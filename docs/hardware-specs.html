Hardware Specifications

Detailed hardware requirements for optimal Securaa SIA platform performance

Overview

Securaa SIA (Securaa Intelligent Automation) hardware specifications are designed to support varying workloads from small POC deployments to large enterprise production environments. This guide provides detailed specifications for different deployment scenarios.

Important: All systems require AVX (Advanced Vector Extensions) CPU support. Verify with: grep avx /proc/cpuinfo

  • Scalable storage per tenant

  • Total: 1.5 TB+

Important Considerations

CPU Requirements

  • AVX support is mandatory
  • Intel Xeon or AMD EPYC recommended
  • Higher clock speed benefits single-threaded tasks
  • More cores benefit concurrent operations

Memory Considerations

  • ECC memory recommended for production
  • MongoDB requires 50% of RAM for WiredTiger cache
  • Elasticsearch heap should be 50% of RAM (max 32 GB)
  • Reserve memory for OS and other services

Storage Considerations

  • SSD storage is mandatory
  • NVMe preferred for database workloads
  • RAID 10 recommended for production
  • Plan for 20% free space at all times

Scalability Planning

  • Plan for 50% growth capacity
  • Multi-VM deployment allows horizontal scaling
  • Consider future TIP integration requirements
  • MSSP deployments benefit from dedicated database servers
