Installation & Deployment Guide

Step-by-step guide for installing and deploying Securaa platform.

Before You Begin: Ensure all prerequisites are met including supported OS, AVX CPU support, and network connectivity to required URLs.

Installation Overview

Securaa uses a Docker-based containerized architecture. The installer will automatically:

  • Install and configure Docker on your system
  • Pull required Docker images from Securaa's container registry
  • Configure MongoDB and Elasticsearch databases
  • Set up Nginx web server with SSL
  • Start all Securaa services

Pre-Installation Checklist

1

Verify Operating System

Ensure you are running a supported operating system:

# Check OS version
cat /etc/os-release

Supported: RHEL 9.x/8.x, Rocky Linux 8.x, Alma Linux 8.x, CentOS 9.x, Ubuntu 20.04x/22.04x

2

Verify AVX CPU Support

Securaa requires AVX (Advanced Vector Extensions) CPU support:

# Check for AVX support
grep avx /proc/cpuinfo

If output shows "avx" flags, your CPU is supported.

3

Install wget

The wget utility is required for the installation:

# RHEL/CentOS/Rocky/Alma
sudo yum install wget -y

# Ubuntu
sudo apt-get install wget -y
4

Verify Network Connectivity

Ensure the server can access required URLs:

# Test connectivity to Securaa release server
curl -I https://release.securaa.io:9002

# Test connectivity to Docker registry
curl -I https://registry-1.docker.io

Installation Process

Step 1: Download the Installer

Download the Securaa installation script from the release server:

# Download the installer
wget https://release.securaa.io:9002/installer.sh

# Make it executable
chmod +x installer.sh

Step 2: Run the Installer

Execute the installer with root privileges:

# Run the installation
sudo ./installer.sh
Note: The installer is interactive and will prompt for configuration options such as deployment type, database settings, and SSL certificate configuration.

Installation Options

During installation, you will be prompted to select:

Option Description Default
Deployment Type Single VM or Multi VM deployment Single VM
Environment Enterprise/Standalone or MSSP Enterprise
SSL Certificate Self-signed or custom certificate Self-signed
TIP Installation Include TIP module Optional

Step 3: Verify Installation

After installation completes, verify all services are running:

# Check Docker containers
docker ps

# Check Securaa services status
docker-compose -f /opt/securaa/docker-compose.yml ps

Post-Installation Configuration

Access the Web Interface

After successful installation, access the Securaa web interface:

https://<your-server-ip>:443

Default Credentials

Security Warning: Change the default password immediately after first login!
Field Default Value
Username admin@securaa.io
Password password

Initial Configuration Steps

1

Change Admin Password

Navigate to User Settings and change the default admin password to a strong, unique password.

2

Configure SMTP Settings

Set up email notifications by configuring SMTP settings under Administration > Settings > SMTP.

3

Add Tenants (MSSP Only)

For MSSP deployments, create tenant configurations under Administration > Tenants.

4

Configure Integrations

Add your security tool integrations under Integrations to start collecting alerts and executing actions.

Tenant Configuration (MSSP)

TIP (Threat Intelligence Platform) Installation

If TIP was not included in initial installation, you can add it later:

TIP Installation Steps

1

Download TIP Installer

wget https://release.securaa.io:9002/tip-installer.sh
chmod +x tip-installer.sh
2

Run TIP Installation

sudo ./tip-installer.sh
3

Configure TIP Connection

After installation, configure the TIP connection in Securaa:

  • Navigate to Administration > TIP Settings
  • Enter TIP server URL (port 7000)
  • Test connection and save

TIP Hardware Requirements

Environment CPU RAM Storage Capacity
POC 4 Cores 16 GB 300 GB SSD ~20 Million records
Production 8 Cores 32 GB 500 GB SSD ~30 Million records

Multi-VM Deployment

For production environments, a multi-VM deployment is recommended for better performance and scalability.

2-Server Deployment

Server Components Installation Order
Server 1 - Database MongoDB, Elasticsearch Install first
Server 2 - Application Securaa Services, Nginx, React UI Install after database server

3-Server Deployment

Server Components Installation Order
Server 1 - MongoDB MongoDB database Install first
Server 2 - Elasticsearch Elasticsearch cluster Install second
Server 3 - Application Securaa Services, Nginx, React UI Install last
Note: When running the installer on the application server for multi-VM deployment, provide the IP addresses of the database servers when prompted.

SSL Certificate Configuration

For production deployments, configure a valid SSL certificate:

Using Custom SSL Certificate

# Copy certificate files to Securaa directory
sudo cp your-certificate.crt /opt/securaa/ssl/server.crt
sudo cp your-private-key.key /opt/securaa/ssl/server.key

# Restart Nginx to apply changes
docker restart securaa-nginx

Using Let's Encrypt

# Install certbot
sudo yum install certbot -y  # RHEL/CentOS
# or
sudo apt-get install certbot -y  # Ubuntu

# Obtain certificate
sudo certbot certonly --standalone -d your-domain.com

# Copy to Securaa directory
sudo cp /etc/letsencrypt/live/your-domain.com/fullchain.pem /opt/securaa/ssl/server.crt
sudo cp /etc/letsencrypt/live/your-domain.com/privkey.pem /opt/securaa/ssl/server.key

# Restart Nginx
docker restart securaa-nginx

Common Installation Issues

Issue Symptoms Solution
Docker Pull Fails Unable to pull images from registry Verify network connectivity to Docker registry URLs. Check firewall rules.
AVX Not Supported Installation fails with CPU error Use a VM or physical server with AVX-capable CPU. Check with: grep avx /proc/cpuinfo
Port Already in Use Services fail to start Check for existing services on ports 443, 8000, 7000. Stop conflicting services.
Insufficient Disk Space Installation fails or services crash Ensure minimum 250 GB SSD available. Clean up unnecessary files.
Database Connection Failed Services cannot connect to MongoDB/ES For multi-VM: Verify database server IPs are correct and ports are open.
Web Interface Not Loading Browser shows connection error Check Nginx container status: docker logs securaa-nginx

Checking Container Logs

# View logs for all containers
docker-compose -f /opt/securaa/docker-compose.yml logs

# View logs for specific service
docker logs securaa-api
docker logs securaa-nginx
docker logs securaa-mongodb
docker logs securaa-elasticsearch

Restarting Services

# Restart all Securaa services
cd /opt/securaa
docker-compose restart

# Restart specific service
docker restart securaa-api

Upgrading Securaa

To upgrade an existing Securaa installation:

1

Backup Current Installation

# Backup database
docker exec securaa-mongodb mongodump --out /backup/mongodb

# Backup configuration
cp -r /opt/securaa/config /backup/securaa-config
2

Download Upgrade Script

wget https://release.securaa.io:9002/upgrade.sh
chmod +x upgrade.sh
3

Run Upgrade

sudo ./upgrade.sh
4

Verify Upgrade

# Check version
docker exec securaa-api cat /opt/securaa/VERSION

# Verify services
docker-compose -f /opt/securaa/docker-compose.yml ps
