Supported Protocols & Standards

Protocol/Standard Description Use Cases
REST API Modern web API standard using HTTP methods Most modern security tools, real-time data exchange
STIX/TAXII Structured Threat Information eXpression Threat intelligence sharing, IOC exchange
Syslog (RFC 5424) Standard logging protocol Log collection from network devices, servers
CEF Common Event Format ArcSight integration, structured event data
LEEF Log Event Extended Format IBM QRadar integration
SNMP v2c/v3 Simple Network Management Protocol Network device monitoring, traps
Webhooks HTTP callbacks for real-time events Real-time notifications, event-driven automation
GraphQL Query language for APIs Modern API integrations, flexible queries
