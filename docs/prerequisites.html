Software Prerequisites

Pre-Installation Requirements

1

Install wget

The wget utility must be installed on the server before running the Securaa installer.

# RHEL/CentOS/Rocky/Alma
sudo yum install wget -y

# Ubuntu
sudo apt-get install wget -y
2

Verify AVX Support

Securaa requires AVX (Advanced Vector Extensions) CPU support. Verify with:

grep avx /proc/cpuinfo

If output shows "avx", your CPU supports AVX.

3

Network Connectivity

Ensure the server has internet connectivity to download Docker images and installation packages. Verify connectivity to required URLs.

4

Root Access

Root or sudo access is required for installation. The installer will configure Docker, system services, and firewall rules.

Platform Components (Installed Automatically)

Docker

Container runtime for running Securaa services. Installed and configured automatically by the installer.

MongoDB

Primary database for storing incidents, cases, playbooks, and configuration data.

Elasticsearch

Search and analytics engine for log data, threat intelligence, and full-text search capabilities.

Nginx

Web server and reverse proxy handling HTTPS termination and serving the React frontend.

POC Prerequisites

1

Environment Preparation

Prepare a dedicated VM/server meeting hardware requirements. Ensure isolation from production systems during POC evaluation.

2

Data Sources

Identify SIEM, EDR, firewall, and other security tools for integration. Prepare API credentials and connection details.

3

Use Cases

Define 2-3 primary use cases to validate during POC. Common use cases include phishing response, malware containment, and vulnerability management.

4

Team Availability

Ensure security team members are available for training, configuration, and evaluation activities throughout the POC period.

Security Requirements

SSL/TLS Certificates

Valid SSL certificates required for HTTPS access. Self-signed certificates supported for POC; CA-signed recommended for production.

Authentication

Local authentication supported out-of-box. LDAP, Active Directory, and SAML integration available for enterprise deployments.

Network Segmentation

Recommended to deploy Securaa in a management network segment with controlled access to security tools and endpoints.

Data Encryption

All data encrypted in transit (TLS 1.2+). Database encryption at rest available for production deployments.
